Direct browser-to-browser multiplayer with join codes and usernames.

Play

Start a room or join a friend.

How it works

  1. One player creates a room and gets a code.
  2. Everyone joins with a username and code.
  3. Gameplay moves directly over WebRTC.
  4. No game backend is needed after the page loads.

Local note

This version is built for static hosting like GitHub Pages. PeerJS is used only for signaling; the game state lives in the browser hosting the room.
